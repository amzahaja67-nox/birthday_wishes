# Ucapan Ulang Tahun

Website ucapan ulang tahun ke-15 untuk Orang penting kamu. Proyek ini dibuat sebagai halaman web statis menggunakan HTML, CSS, dan JavaScript, tanpa proses instalasi atau build.

## Isi website

- Halaman pembuka dengan tombol kejutan.
- Pesan dan doa ulang tahun.
- Galeri empat foto yang dapat dibuka dalam tampilan lebih besar.
- Bagian kenangan dengan penghitung usia, hari, dan jam.
- Tombol perayaan dan pemutar musik latar.
- Efek animasi serta tampilan yang menyesuaikan ukuran layar.

## Struktur folder

```text
.
├── index.html                   # Konten dan susunan halaman
├── style.css                    # Gaya, tata letak, dan animasi
├── script.js                    # Animasi dan interaksi halaman
├── README.md                    # Informasi dan panduan proyek
└── assets/
    ├── audio/
    │   └── Selamat Ulang Tahun.mp3 # Musik latar
    └── images/
        ├── gallery1.png          # Foto galeri
        ├── gallery2.png
        ├── gallery3.png
        └── gallery4.png
        └── favicon.png           # Favicon website
```

## Menjalankan

Buka `index.html` di browser. Jika browser membatasi pemuatan media saat file dibuka langsung, jalankan server lokal dari folder proyek, lalu buka alamat lokal yang ditampilkan server. Musik dapat diputar atau dijeda melalui kontrol di bagian bawah halaman.

Halaman menggunakan Google Fonts, sehingga koneksi internet diperlukan untuk memuat jenis huruf tersebut. File foto dan musik tersedia di folder `assets`.

## Mengubah konten

Ubah teks dan susunan bagian di `index.html`, tampilan di `style.css`, serta animasi dan perilaku tombol di `script.js`. Ganti foto atau musik dengan file baru di folder yang sesuai dan sesuaikan jalur berkasnya di `index.html`.
